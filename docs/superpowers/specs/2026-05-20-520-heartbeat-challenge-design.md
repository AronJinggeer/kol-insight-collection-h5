# 520 心跳挑战 Design

## Goal

在现有 Next.js H5 项目首页落地一个可直接演示的移动端趣味小游戏，围绕“20 秒测出你的财富心动人格”完成完整的开始、倒计时、游戏、结果、海报预览闭环。

## Product Scope

- 单页 H5，通过前端状态切换完成 4 个页面状态
- 纯前端实现，不依赖后端
- 金融社区语境，但不做交易引导、不做奖励体系
- 支持结果页海报预览与前端导出
- 所有文案、称号、判定规则、概率和分数集中配置

## Visual Direction

- 主色使用奶油黄、米黄色、浅金色，避免交易软件式深色或高压对比
- 情绪方向为“520 温暖感 + 社区轻互动 + 轻微金融符号”
- 背景用柔和渐变、心跳线、轻 K 线、金币光点做浅层氛围，不做复杂重装饰
- 卡片、按钮、海报都保持圆角、柔和阴影和轻微漂浮动效

## Page States

### Start

- 展示活动标题、副标题、三色心的主视觉和玩法提示
- 显示唯一主按钮“开始挑战”
- 底部固定展示合规文案

### Countdown

- 用户点击开始后进入 3 秒倒计时
- 依次显示 `3 / 2 / 1 / 心动开始`
- 倒计时结束自动进入游戏态

### Playing

- 顶部展示剩余时间、当前得分、当前连击
- 中间为随机心形掉落区
- 底部展示动态提示文案
- 20 秒结束后自动结算

### Result

- 展示称号、总分、命中率、最高连击、三种点击统计
- 展示主文案、520 签名、海报预览区
- 展示按钮：生成我的心动海报 / 再玩一次 / 去社区晒成绩
- 显示结果页补充合规文案

## Game Rules

- 红心：+10 分，成功命中
- 金心：+15 分，成功命中
- 绿心：-10 分，分数最低为 0，且清空连击
- 连击 5 次额外 +20
- 连击 10 次额外 +50
- 奖励仅在命中后按当前连击数结算，不重复补发
- 心形每 600-900ms 生成 1-3 个
- 心形停留 800-1200ms 自动消失
- 概率：红 45%，金 30%，绿 25%

## Architecture

### Config Layer

在 `lib/heartbeat-game-config.ts` 集中定义：

- 文案
- 称号库
- 动态提示语
- 概率与分数
- 海报文案

### Logic Layer

在 `lib/heartbeat-game.ts` 提供纯函数：

- 命中率计算
- 连击奖励计算
- 结果类型判定
- 结果内容抽取
- 海报 SVG 生成

这层保持与 UI 解耦，便于测试和后续接社区容器。

### UI Layer

在 `components/home-page.tsx` 直接替换首页为游戏 H5，并按职责拆出局部渲染单元：

- StartScreen
- CountdownScreen
- GameScreen
- ResultScreen
- PosterPreview
- HeartItem
- ScorePanel

首版允许这些单元放在一个文件内，但逻辑与配置必须分层。

## Result Mapping

结果类型按以下优先级判定：

1. 高分王者
2. 冷静类
3. 黄金类
4. 股票类
5. 基金类
6. 均衡类

所有类型只返回正向称号与文案，不出现负面反馈。

## Poster Strategy

- 结果页内置一个可见海报卡片作为预览
- 点击“生成我的心动海报”时，前端基于结果数据拼接 SVG 海报
- 使用浏览器下载链接导出 SVG 文件，避免引入额外库，保证纯前端可上线
